### 🚀 About My Journey

> *"Every expert was once a beginner. The journey of building great software starts with curiosity and daily practice."*

I am an enthusiastic **Software Engineering Fellow at Semicolon Africa**, currently on an exciting journey exploring the worlds of **Backend Development** and **Data Science**. 

Rather than chasing shortcuts, I believe in understanding fundamentals from the ground up:
- 💡 Built foundational knowledge in **Java**, **Spring Boot**, and **Maven** for structured backend applications.
- ⚡ Explored modern, asynchronous web APIs using **Python** and **FastAPI**.
- 📊 Learned the essentials of **Data Science** to extract meaningful insights from data.
